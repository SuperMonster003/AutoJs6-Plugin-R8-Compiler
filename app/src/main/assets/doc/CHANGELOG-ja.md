# v0.1.0-provider-dev (local.1)

###### 2026/08/25

* `ヒント` 初のローカル署名リリース (bootstrap 世代); オフラインの 2 スナップショットがバイト単位で一致する再現ビルドにより, append-only なローカルリリースディレクトリを確立
* `機能` AutoJs6 向けの明示的 R8 コンパイラプラグイン: スクリプトは `runtime.loadJarWithR8()` で完全な release コンパイル (shrinking + optimization + obfuscation) を要求
* `機能` 一度のコンパイルで 5 つの成果物を返却: DEX ZIP, mapping, seeds, usage, retrace メタデータ. それぞれ SHA-256 に紐付き, ホストが独立して再検証
* `機能` 無フォールバックの意味論: あらゆる失敗は R8 エラーとして終わり, 黙って D8/dx に切り替わることはありません; ホストは専用の R8 キャッシュドメイン `autojs6:r8-compiler:v1` を使用
* `機能` コンパイルはプラグイン独自の `:r8` プロセス内の私有サンドボックスで実行され, 同一署名の AutoJs6 呼び出しのみを受け入れ (`org.autojs.permission.PLUGIN` 権限で保護), ネットワークとストレージの権限を持ちません
* `機能` 厳格な入力検証: パスを含まない正準入力バンドル, 危険指令を fail-closed で拒否する厳密 UTF-8 ルール, アーカイブ・クラスデータ・出力の各段階の強制上限
* `機能` コンパイラ minApi 24-36 の全数カバー: リフレクション, 実行時合成名, JNI, シリアライズ, 除去デコイ検証を含む 26 セルの Java/Kotlin 実 R8 互換コーパス
* `機能` 純粋な JVM 実装; ユニバーサル APK 1 つで全デバイスアーキテクチャをカバー
* `依存関係` Google R8 8.13.17 を同梱 (Maven `com.android.tools:r8`)
