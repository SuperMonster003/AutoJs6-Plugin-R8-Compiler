# v0.1.0-provider-dev (local.1)

###### 2026/08/25

* `Подсказка` Первый локальный подписанный выпуск (поколение bootstrap); воспроизводимая сборка с двумя побайтово идентичными офлайн-снимками, заложившая append-only каталог локальных выпусков
* `Функция` Явный плагин компилятора R8 для AutoJs6: скрипты запрашивают полную release-компиляцию (shrinking + optimization + obfuscation) через `runtime.loadJarWithR8()`
* `Функция` Одна компиляция возвращает пять артефактов: DEX ZIP, mapping, seeds, usage и метаданные retrace; каждый привязан к SHA-256 и независимо перепроверяется хостом
* `Функция` Семантика без отката: любой сбой завершается ошибкой R8 и никогда не переключается втихую на D8/dx; хост использует выделенный кэш-домен R8 `autojs6:r8-compiler:v1`
* `Функция` Компиляция выполняется в собственном процессе `:r8` плагина в приватной песочнице, принимает только вызовы AutoJs6 с той же подписью (защита разрешением `org.autojs.permission.PLUGIN`), без разрешений на сеть и хранилище
* `Функция` Строгая проверка ввода: канонический входной пакет без путей, строгие правила UTF-8 с fail-closed отклонением опасных директив, жёсткие лимиты на архивы, данные классов и вывод
* `Функция` Полное покрытие `minApi` 24-36 компилятора: реальный корпус совместимости R8 из 26 ячеек Java/Kotlin с рефлексией, составляемыми в рантайме именами, JNI, сериализацией и проверкой удалённой приманки
* `Функция` Чисто JVM-реализация; один универсальный APK покрывает все архитектуры устройств
* `Зависимость` В комплекте Google R8 8.13.17 (Maven `com.android.tools:r8`)
